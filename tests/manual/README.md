# Manual cloud tests

These playbooks create billable ECS resources and are deliberately kept out of
the default `tests/` playbook set. Run them only in a dedicated test account.

`ali_image_and_encryption_test.yml` requires the following environment
variables:

```shell
ALICLOUD_ACCESS_KEY
ALICLOUD_SECRET_KEY
ALICLOUD_REGION
ALICLOUD_TEST_ZONE_ID
ALICLOUD_TEST_IMAGE_ID
ALICLOUD_TEST_INSTANCE_TYPE
ALICLOUD_TEST_KMS_KEY_ID
```

The RAM principal needs permission to create and delete VPC, vSwitch, security
group, ECS instance, disk, and custom image resources, and permission to use
the supplied KMS key. It also requires the `aliyun` CLI in `PATH` to remove
the snapshots generated by the temporary image. The playbook removes its
image, snapshots, instance, and network resources in an `always` block.
